# Workout

An original dark React Native training journal built around consistency. Expo SDK 58, React Native 0.88, Expo Router and TypeScript. Android package: `dev.anay.workout`.

## What works

- Personal onboarding: goal, experience, available equipment, preferred training days, optional height and body-weight target. Generates editable routines from those choices.
- Real offline workouts: weighted, bodyweight, timed and cardio sets; previous performance; warm-ups, drop/failure sets, RPE, supersets, notes and session feeling. Pause/resume, minimize, recover an unfinished session after restart, and edit completed workouts.
- Rest timers with per-exercise settings and optional Android notifications. Optional weekly training reminders on your chosen days.
- 76 built-in movements, instructions, muscle/equipment search, favorites and custom exercises. Create, order, copy, schedule and delete routines; repeat a workout or save it as a routine.
- Calendar history, weekly goal progress, training-day and weekly-goal streaks, 12-week activity heatmap, volume/time/set charts, exercise records and estimated 1RM trends.
- Interactive SVG front/back muscle maps showing direct and assisting sets. These represent logged work, not measured recovery or medical anatomy.
- Body-weight, waist, body-fat and lean-mass history, trend graphs, BMI from your entered height, and target-weight progress.
- Five saved dark themes: **Chalk, Volt, Cobalt, Amber, Solar**. Volt is the first-launch default. Lucide icons and original SVG diagrams.
- Validated JSON backup export/restore, including unfinished workouts. Recovery screen preserves an unreadable journal and lets you export the existing file before restoring a backup.

The installed app starts with an empty journal. Test fixtures and screenshot data are never bundled into the app. Your name, measurements and training preferences come from onboarding; no personal health values have been assumed.

## Cult Smart Body Fat Scale / Cult Connect

Open **You → Cult scale & body data**. The app can open Cult Connect (`fit.cure.android.cswatch`) on Android.

1. **Health Connect:** requests read access to Weight, Body Fat and Lean Body Mass, previews the last 30 days, shows the data origin, and imports only readings you select and confirm belong to you. Existing record IDs are deduplicated. Fat/lean values are associated only with readings from the same origin within two minutes.
2. **Direct Bluetooth:** scans nearby devices when requested, connects only to the device you select, and checks the standard Bluetooth Weight Scale service (`0x181D` / `0x2A9D`). Supports standard metric/imperial packets. You confirm a reading before saving it. The app does not guess proprietary packets or collect scale data in the background.
3. **Manual entry:** weight, waist and optional body-fat / lean-mass measurements work independently of either integration.

**Physical Cult-scale compatibility is unverified.** No phone or scale was connected during development. Cult Connect's public documentation does not establish that it exports these measurements to Health Connect, and the scale may use a private BLE protocol. The screen reports unsupported devices rather than claiming a successful sync. The scale's other advertised parameters are not fabricated. Body composition readings are device estimates.

## Data and calculations

Training data is an atomically written SQLite document on Android; the web preview uses browser local storage. Changes are serialized, failed writes show a retry action, and validation prevents an unreadable journal from being silently replaced. Clearing app storage or uninstalling removes local data; export a backup through **You** first. Backup files contain your personal training and body data; save them somewhere you trust.

Working-set analytics exclude warm-ups, unfinished sets and invalid entries. Lifting volume is weight × reps for weighted exercises. Bodyweight/timed/cardio movements do not invent a kg total. Estimated 1RM uses Epley only for 1–12 reps, with a single treated as the actual weight. Weekly goals count distinct training days, so two sessions on one day count as one day. Muscle workload distinguishes primary from secondary muscles. Changing/deleting history recalculates graphs and records.

There is no app account, social feed, subscription, analytics SDK or app backend. Local Android notifications depend on system permission and battery settings. The current version uses kilograms, centimetres and kilometres; standard Bluetooth pound measurements are converted to kg. No calorie or recovery score is inferred from workout logs.

## Verification

```sh
npm run typecheck
npm run lint
npm test
npx expo-doctor
```

Browser checks use Playwright and local Chromium. Start the web server on port 8095, then:

```sh
node tests/mobile-flow.mjs
node tests/recovery-flow.mjs
node tests/visual-flow.mjs
```

Set `WORKOUT_TEST_URL` and `CHROMIUM_PATH` to override the defaults. Run these in order: the first writes an isolated synthetic fixture under ignored `screenshots/qa/`, used by the next two. They do not modify your normal browser journal.

Unit checks cover validation, calculations, pause duration, records after edits/deletes, unique training days, backup round trips, malformed scale packets, and 252 personalization combinations. Browser flows cover onboarding, logging/reload/resume/finish, measurements, custom exercises, favorites, routine copies, historical edits, backups and corrupted-storage recovery, longer histories and all five themes. Android/physical-device verification details are recorded in `docs/VERIFICATION.md`.
